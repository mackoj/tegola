  - `TegolaDesignTokens` holds the archive's palette, 38 theme roles, the Board theme, and the type, spacing, radius,

  - the SwiftUI side has the theme in the environment, colour and font resolution, and font registration, with the
    three OFL fonts and their licences.
- **Guard tests** over every source file:
  - no `Date()`, `UUID()`, `Locale.current`, `Calendar.current` or `URLSession.shared`;
  - no `print`;
  - no colour literal outside the tokens, and no system colour;
  - no `.public` log interpolation;
  - the pure packages and the tokens import no Apple UI framework;
  - each rule also proves it catches its own sample.
- **The app shell:**
  - `Tegola.xcodeproj` with the app, `TegolaTests` and `TegolaUITests`, bundle id `fr.macko.tegola`, iOS 26.0;
  - `AppFeature` with the five tabs, where Scan presents;

## Review

A separate review agent read the M1 code against this plan, concentrating on the code nobody could compile here. It
found 14 problems. All are fixed on this branch:

1. **SwiftUI's own `Tab`.** SwiftUI has a `Tab` type (iOS 18) that would make `AppView` ambiguous. The model's type
   is now `AppTab`.
2. **Missing direct import.** `AppFeatureTests` used `TegolaModel`'s cases without importing it, which
   `MemberImportVisibility` forbids. It now imports it and depends on it.
3. **Missing package.** `test.sh` and `ci.sh` listed `TegolaStorage`, which doesn't exist until M2, so both would
   always fail. Packages that don't exist yet are now skipped, and the stale `TegolaClients` pattern is gone.
4. **Guard tests too narrow.** They now catch:
   - `.foregroundStyle(.red)`, `.tint(.blue)` and `.secondary`;
   - `Date.now`, `Locale.autoupdatingCurrent` and `TimeZone.current`;
   - 8-digit hex, and P3, hue and white colours;
   - every import spelling, including `import struct SwiftUI.Color`, which slipped past `\b` under Unicode word
     boundaries.

   New rules cover palette colours outside a theme, font names and system fonts outside `Fonts.swift`, and
   un-bundled UI strings. A String Catalog coverage test is new too.
5. **False claims in this report and BOARDS.md**, now corrected:
   - the role count;
   - the missing `TegolaClients` target (D-31);
   - the teal contrast row, which said it was tested when it wasn't.
6. **Meta labels on dark surfaces.** The darker `metaText` would be 2.74:1 on ink. A `textMetaOnStage` role keeps
   the archive's grey there (4.71:1 on ink, 5.04:1 on the camera), and both pairs are now tested.
7. **Fonts could silently fall back to SF Pro.** The variable fonts register under their default instance, so styles
   now open that face by PostScript name and set `wght` (and Bricolage's `opsz`) through CoreText. A Mac test checks
   that each style resolves to its own family and weight. Dynamic Type scaling and line height are applied, and
   `numeric` uses a bundled DM Mono weight.
8. **Numbered places.** "Rack 3" and "Rack 4" were offered as a merge. Numbers must now match.
9. **Tab order decoding.** A stored tab order with an unknown tab threw an error instead of falling back to the
   default.
10. **Delimited-text parser.**
    - An unterminated quote now throws and names its line.
    - Spaces around a quoted cell are dropped.
    - A line holding only `""` is kept as a row.
11. **Type file strictness.** Unknown keys in a type file, a field or a subtype are now errors. Malformed presets are
    an error, not an empty set. Ids must be ASCII kebab-case and match their file name.
12. **Paths with spaces.** Source scanning broke on a clone path with spaces; it now uses unencoded paths.
13. **Unpinned packages in the Xcode project.** It now has a `Package.resolved` pinned to the packages' resolution
    (TCA 1.26.2).
14. **The manual CI job** now picks an available iPhone simulator instead of naming one. It stays on Xcode 26.6 on
    purpose, to check the iOS 26 SDK build.
