The screens, each against its board (`docs/design/BOARDS.md`), with the PD log deciding what's there. Screenshots are
the snapshot references in `docs/snapshots/`.

- **Design system** (T3.1):
  - the printed look (ink edge, hard offset shadow), not-yours dashes and halftone;
  - DisplayTitle (one `Text` per line, so the 0.96 line height holds) and ScreenHeader;
  - buttons, pills, chips, the five status chips, empty state, and the compact, stage and modal bars;
  - the tab bar with the raised scan button;
  - type tints, collection tiles, rows, the count banner;
  - the ladder and set signatures, the history timeline;
  - form fields, choice chips over a wrapping layout.
  
  `DesignSystemCatalog` renders every component and variant, and its sections are snapshots
  (`docs/snapshots/catalog/`).
- **Read side** (T3.2): `Route`, `ShelfSummary`, `TodayStrip`, `CollectionMeta`, `ObjectSlots`, the money setting.
  Promises 4 and 5 join the property tests (D-43, D-44).
- **Navigation** (T3.3): the real tab bar, a stack each for Shelf and Find, and `AppPath`. Children send a route and
  only the root pushes.
- **Shelf home** (T3.4, F3, board 01): the Catalogued banner (or the value with money on), the Today strip with its
  non-empty lines only, the collections as tiles in their type's tint, the wishlist as a dashed tile, the Places line
  once two places exist, and board 02's empty shelf with **Type it** (D-47).
- **Collection** (T3.5, F4, board 03): rows, the mono meta line, sort, a place filter, rename, a mixed collection
  grouped by type.
- **Object** (T3.6, F4, board 04 under PD-013): the seven slots in order, for every v1 type (D-48):
  - hero: the photo, or the type's flat hero;
  - spine;
  - status: one chip;
  - signature: ladder and set;
  - fields: with AUTO badges;
  - actions: Edit, Photo, Might let go;
  - history: newest first.
- **Edit form** (T3.7, F5, board 13): one control per field kind over the resolved type. Cancel writes nothing; Save
  writes one `edited` event naming exactly the changed keys. `plan` now checks every value against its field (D-40
  closed, D-49).
- **Add by hand** (T3.8, F6): pick a type, then an optional subtype, Add to (the last collection used), and the same
  form. The first object of a type creates its collection. "Save, add another" keeps the type and collection (D-50).
- **Photos** (T3.9): a photo file outside the database and a row in it. The object's Photo action opens the system
  picker, and the hero shows the photo.
- **Find** (T3.10, F11, board 07):
  - search over every field, note, entry and place, with each result naming what matched;
  - stacking chips for type, lent out and the archive;
  - saved views: Imperfect, Duplicates, Signed, Might let go.
  
  Search is pure Swift for now (D-51).
- **Places** (T3.11, F10): the list with a one-tap merge for near duplicates, and a place's screen (D-52).

## Review

A separate review agent read T3.1 to T3.11 against the plan, PLAN §3.4, §4 and §5, and D-40 to D-52. It found nine
bugs, three tests that didn't test what they claimed, and three spec disagreements. All are fixed or answered (D-53).

1. **The Places screen counted wanted, borrowed and quantity objects wrong.** It now uses `count(_:)` (promise 4).
2. **A ladder part couldn't be marked Missing.** Now it can, but only where the type allows it. The ladder draws it
   as a dashed rung, and VoiceOver reads each part's grade.
3. **Duplicates included signed copies.** A signed object is one of a kind.
4. **Money on with nothing valued showed an empty figure.** The count stands instead.
5. **An empty list entry made an object Signed.** Empty entries are no value.
6. **A place merge always kept the older name.** Both directions are offered.
7. **Saves were partial.** Add by hand reports a later failure without reopening the save (no duplicate on a second
   tap), and every error is caught.
8. **Find had no place filter, and the Archive chip alone did nothing.** Both work now.
9. **The ladder's fixed sizes clipped at large Dynamic Type.** They're gone.
10. **The seven-slots test only checked a constant.** The object view now draws its slots by walking
    `ObjectSlots.order`, so the constant is the order.
11. **The last-used test passed whatever the default.** It now uses a mixed collection as the last one used.
12. **The command generator never merged places.** It does now, so the promise and replay tests cover merges.

Answered rather than fixed:
- **D-44 and D-50 disagreed** about when settings are first written. D-44 is reworded.
- **A lookup refused its whole answer over one value** that didn't fit. It now drops that value.
- **D-51's pure search** changes T3.10's acceptance; that's for the owner to decide (below).

Nits taken: let-go objects' places leave the collection's filter, the duplicate place-tree helper is gone, title
checks trim newlines too, changing type clears the place, and `test.sh ios:` runs without `timeout` where it's
missing. Nits left: money-kind fields aren't hidden with money off (no v1 type has one), and `FlowLayout` measures
chips at their ideal width.
