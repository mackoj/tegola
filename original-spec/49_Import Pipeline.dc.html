03B · CLCTN.CSV · THE FAST LANE, NEVER THE ONLY LANE
A template we publish, with one row per item and fixed headers. If a file matches it, there's no model and no guessing, and the import is instant and free. The template is optional, though. Your friend won't rewrite 485 cells into new columns, and asking him to would lose him before the first box shows up. The template is for people starting from scratch, and it's the same format the app exports. Exporting and re-importing a collection gives back exactly what went out, and that's what makes people trust the app with their data.

06 · HOW IT'S GROUPED · ONE COLLECTION, NOT TWENTY
A collection is a choice the user makes. A platform is a fact about the game. His file is called Jeux collection, and he chose to keep it as one sheet. So the import creates exactly one collection, “Jeux”, and the 20 platforms become shelves inside it, generated from the subtype. Twenty collections would be a mess on day one: Switch would get a collection for one game and CD-i one for three.
